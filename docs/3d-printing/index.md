# 3D Printing

A reference for desktop **FDM** 3D printing — how it works, the filaments and their
settings, slicer tuning, and fixing prints when they go wrong. Written as a general
reference rather than a build log; settings are compiled from manufacturer and
community sources and linked at the bottom of each page.

<div class="grid cards" markdown>

-   :material-printer-3d-nozzle:{ .lg .middle } __[Basics](basics.md)__

    ---

    How FDM works, the parts of a printer, the model-to-print workflow, and the
    core vocabulary.

-   :lucide-layers:{ .lg .middle } __[Filaments](filaments.md)__

    ---

    Every common filament — settings, notes, pros/cons, and use cases. PLA, PETG,
    ABS/ASA, TPU, nylon, PC, composites, and supports.

-   :lucide-settings:{ .lg .middle } __[Print Settings](print-settings.md)__

    ---

    Slicer settings that matter — layers, walls, infill, temperature, speed,
    retraction, cooling, supports, and adhesion.

-   :lucide-wrench:{ .lg .middle } __[Troubleshooting](troubleshooting.md)__

    ---

    Common print defects — warping, stringing, under-extrusion, delamination — with
    causes and fixes.

</div>

!!! tip "New to it?"

    Start with **[Basics](basics.md)**, print in **PLA** while you learn, then reach
    for **[Filaments](filaments.md)** when you need a part that's strong, flexible,
    or weatherproof.
